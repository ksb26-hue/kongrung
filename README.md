## ✨ 학생 페이지에서 할 수 있는 것

### 📅 달력으로 한눈에 예약
- **오늘**은 파란색으로 표시
- 날짜마다 **잔여 담요 수** (`잔여 3/9`) 표시
- 다 빌려가면 → **마감**
- 방문 교시(아침·점심)가 지나면 오늘도 **마감**
- 토·일은 **주말**이라 예약 불가

### ⏰ 방문 교시 선택
- 아침시간 `08:40`
- 점심시간 `01:00`
- 이미 지난 시간은 `(마감)` 처리

### 📢 실시간 공지 · 세탁일 · 날씨
- 학생회 공지사항
- 최근 세탁 / 소독일
- 오늘 날씨 (살짝 보너스)

### 🧾 내 예약 확인 / 취소
- 같은 폰이면 예약이 바로 보여요
- 학번으로도 조회 가능
- 잘못 예약했으면 취소도 OK

### 🚨 익명 건의함
- 담요 훼손 신고
- 불편한 점 자유롭게 남기기  
  (이름 안 나와요)

## 📖 이용 규칙 (프론트에도 그대로 있어요)

1. 1인 1일 1회, **주 2회**까지
2. **토·일 예약 불가**
3. 빌린 날은 **종례 전까지 반납**
4. 무단 연체·훼손 → **2주 정지**
